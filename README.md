# Weather App

A simple weather app that shows current weather, wind speed, rain chance, and a 24-hour forecast for any location.

## Live Demo

[View on GitHub Pages](https://vidhyawalke.github.io/Weather-Web-App/)

## Features

- Search weather by city or location
- Shows temperature, wind speed, humidity, rain chance, and condition
- 24-hour hourly forecast
- Auto-detects your current location on load
- Refresh button to reload weather data

## API

Uses the [Visual Crossing Weather API](https://www.visualcrossing.com/weather-api).

## Usage

Open `index.html` in a browser, or visit the GitHub Pages link above.
